# Как подключить Google Таблицу и выложить сайт

Сайт на GitHub Pages — это просто файлы, своей базы данных у него нет. Поэтому классы, ученики и их прогресс
хранятся в **Google Таблице** автора. Внутри таблицы работает маленькая программа на **Google Apps Script**
(файл [`backend/Code.gs`](../backend/Code.gs)) — она и есть «сервер» БитБлокнота.

Пока таблица не подключена, сайт работает в **демо-режиме**: всё хранится только в одном браузере.

---

## Часть 1. Google Таблица (≈ 10 минут)

1. Откройте [sheets.new](https://sheets.new) — создастся новая таблица. Назовите её, например, «БитБлокнот — база».
2. В меню выберите **Расширения → Apps Script**. Откроется редактор кода.
3. Удалите всё, что там написано, и вставьте целиком содержимое файла `backend/Code.gs`. Нажмите **Сохранить**.
4. Справа вверху нажмите **Начать развёртывание → Новое развёртывание**.
   - Нажмите рядом с «Выберите тип» → **Веб-приложение**.
   - **Описание:** «БитБлокнот».
   - **Запуск от имени:** «Я (ваша почта)».
   - **У кого есть доступ:** «**Все**» (иначе ученики не смогут войти).
   - Нажмите **Начать развёртывание**.
5. Google попросит разрешение: **Предоставить доступ** → выберите свой аккаунт.
   Появится предупреждение «Приложение не проверено» — это нормально для своих скриптов:
   нажмите **Дополнительные настройки → Перейти на страницу «БитБлокнот» (небезопасно) → Разрешить**.
6. Скопируйте **URL веб-приложения** — он заканчивается на `/exec`.
7. Проверка: откройте этот адрес в браузере. Должно появиться `{"ok":true,"app":"bitbloknot",...}`.
8. Откройте файл [`js/config.js`](../js/config.js) и вставьте адрес в кавычки:
   ```js
   export const API_URL = "https://script.google.com/macros/s/.../exec";
   ```
   (или просто пришлите адрес Коту — он вставит).

Листы `Teachers`, `Sessions`, `Classes`, `Students` появятся в таблице сами после первой регистрации учителя.

### Если поменяли `Code.gs`

Скопируйте новый код в редактор Apps Script, сохраните, затем **Развёртывание → Управление развёртываниями →
→ Версия: «Новая версия» → Развернуть**. Адрес `/exec` при этом не меняется.

### Учитель забыл пароль

Откройте таблицу, лист **Teachers**, удалите строку с его почтой. Учитель регистрируется заново с той же почтой —
все его классы и ученики останутся (они привязаны к почте).

### Что видно в таблице

- **Classes** — названия классов, их коды и почта учителя.
- **Students** — имена, личные коды, аватары и прогресс (в столбце `progress` — данные в формате JSON).
- Пароли учителей **не хранятся**: только «соль» и хеш (результат необратимой функции SHA-256).

> Совет: в списке учеников лучше писать имя и первую букву фамилии («Петя И.») — так в таблице меньше личных данных.

## Часть 2. GitHub Pages (≈ 3 минуты)

1. Отправьте изменения на GitHub (`git push`).
2. На странице репозитория: **Settings → Pages**.
3. **Source:** «Deploy from a branch», **Branch:** `main`, папка **`/ (root)`** → **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://<ваш-логин>.github.io/bitbloknot/`.

Файл `.nojekyll` в корне говорит GitHub «не обрабатывай файлы, отдавай как есть».

---

## Проверка после публикации

1. Откройте сайт → **Я учитель** → зарегистрируйтесь.
2. Создайте класс «7Б», добавьте пару учеников, откройте **Карточки входа**.
3. На **другом** компьютере или телефоне: **Я ученик** → код класса + личный код → выберите аватар → пройдите шаг урока.
4. В кабинете учителя нажмите **Обновить** — прогресс ученика должен появиться.
