# БитБлокнот

**Интерактивный веб-репетитор по информатике для 7 класса.**
Проект для научно-практической конференции «Инженеры будущего».

БитБлокнот объясняет все 12 тем школьного курса информатики 7 класса (по ФГОС) короткими шагами с иллюстрациями,
даёт поиграть с тренажёрами, генерирует бесконечные задачи и, как живой репетитор, распознаёт типичные ошибки ученика.
Учитель создаёт класс, раздаёт коды входа и видит прогресс каждого ученика.

## Как открыть

- **В интернете:** сайт выкладывается на GitHub Pages — `https://<логин>.github.io/bitbloknot/`.
- **На своём компьютере:** в папке проекта выполните `python -m http.server 8080` и откройте http://127.0.0.1:8080
  (просто открыть `index.html` двойным щелчком нельзя — браузер не разрешит загрузку модулей с диска).

Пока не подключена Google Таблица, сайт работает в **демо-режиме** (всё хранится в одном браузере).
Как подключить таблицу и выложить сайт — [docs/GOOGLE-SHEETS.md](docs/GOOGLE-SHEETS.md).

## Как войти

| | |
|---|---|
| **Учитель** | регистрируется по почте и паролю, создаёт класс (например, «7Б») — система выдаёт **уникальный код класса из 6 цифр**. Вписывает имена учеников — каждый получает **личный код из 4 цифр**. Карточки входа можно распечатать. |
| **Ученик** | вводит код класса и личный код — и сразу попадает к урокам. |

## Что умеет

| | |
|---|---|
| **48 уроков** | 12 тем, в каждой 4 урока — материал на весь учебный год; в каждом шаге объяснение, схема или иллюстрация и вопрос «Проверь себя» |
| **12 тренажёров** | по одному в каждой теме: «Собери компьютер», «Проводник», «Почтальон пакетов», «Сортировщик», «Алфавит и биты», «Лестница единиц», «Шифровальщик», «Пиксельный художник», «Звукозапись», «Мини-редактор», «Растр или вектор», «Исправь слайд» |
| **25 живых иллюстраций** | прямо в шагах урока: сортировка устройств, дерево папок, пакеты в сети, лампочки-биты, смешивание RGB, оцифровка звука, макеты слайдов и другие; три из них объёмные (Three.js) |
| **4 вида вопросов** | выбрать ответ, расставить по порядку, соединить пары, вписать число |
| **Бесконечные задачи** | генераторы для 6 тем, 3 уровня сложности |
| **Диагностика ошибок** | «Похоже, ты перепутал биты и байты» — подсказка именно про твою ошибку |
| **Тесты** | 10 вопросов из банка (470 вопросов в курсе вместе с вопросами после шагов), оценка по пятибалльной шкале, разбор ошибок |
| **Умный репетитор** | блок «Сегодня» советует, что делать дальше, и объясняет почему; повторение через 1, 3 и 7 дней |
| **Кабинет учителя** | несколько классов, добавление и удаление учеников, таблица прогресса по всем темам, частые ошибки каждого ученика, печать карточек входа |
| **Кабинет ученика** | статистика, частые ошибки, 14 значков, серия дней (один пропуск в неделю прощается) |
| **Оформление** | светлая тетрадь в клетку или минималистичная тёмная тема; четыре цвета акцентов: синий, зелёный, жёлтый, красный |
| **Свои значки** | все значки нарисованы для проекта в едином стиле, эмодзи не используются |

## Как устроено

HTML + CSS + JavaScript (сайт на GitHub Pages) и Google Таблица с Apps Script (хранилище классов и прогресса).
Подробное объяснение простым языком — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```
index.html, *.html  — страницы сайта
js/                 — «мозг»: генераторы задач, проверка ответов, умный репетитор, связь с таблицей
js/pages/           — код каждой страницы
trainers/           — тренажёры, illustrations/ — интерактивные иллюстрации
tools/preview.html  — просмотр любой иллюстрации или тренажёра без входа в урок
content/            — тексты уроков и вопросы тестов (JSON)
backend/Code.gs     — «сервер» для Google Таблицы
tests/              — автотесты (node --test)
docs/               — документация, журнал разработки, все вопросы курса
```

## Проверка

```
node --test tests/
```

90 автотестов проверяют генераторы задач (тысячи случайных задач), распознавание ошибок,
правила умного репетитора, достижения, все 48 уроков, «сервер» для Google Таблицы (на поддельной таблице)
и отсутствие эмодзи в файлах проекта.

## Как создавался

Проект сделан методом **вайб-кодинга**: автор продумал продукт, принял все решения
(темы, тренажёры, дизайн, правила репетитора, система входа) и тестировал результат, а программный код писал
ИИ-ассистент Claude по его заданию. Весь ход работы записан в [docs/DEVLOG.md](docs/DEVLOG.md).
