# БитБлокнот

**Интерактивный веб-репетитор по информатике для 7 класса.**
Проект для научно-практической конференции «Инженеры будущего».

БитБлокнот объясняет все 12 тем школьного курса информатики 7 класса (по ФГОС) короткими шагами с иллюстрациями,
даёт поиграть с тренажёрами, генерирует бесконечные задачи и, как живой репетитор, распознаёт типичные ошибки ученика.

## Как запустить

1. Установите [Python](https://www.python.org/downloads/) 3.12 или новее (при установке отметьте «Add Python to PATH»).
2. Дважды щёлкните **`run.bat`**.
3. Сайт откроется в браузере по адресу http://127.0.0.1:5000

При первом запуске нужен интернет, чтобы скачать библиотеку Flask. Потом сайт работает **полностью без интернета**.

## Что умеет

| | |
|---|---|
| 📚 **12 уроков** | по 5–7 шагов, в каждом — схема или интерактивная иллюстрация и вопрос «Проверь себя» |
| 🧪 **7 тренажёров** | «Собери компьютер», «Проводник», «Алфавит и биты», «Лестница единиц», «Шифровальщик», «Пиксельный художник», «Звукозапись» (со звуком!) |
| ♾️ **Бесконечные задачи** | генераторы для 6 тем, 3 уровня сложности |
| 🔍 **Диагностика ошибок** | «Похоже, ты перепутал биты и байты» — подсказка именно про твою ошибку |
| 📝 **Тесты** | 10 вопросов из банка (326 вопросов в курсе), оценка по пятибалльной шкале, разбор ошибок |
| 🧠 **Умный репетитор** | блок «Сегодня» советует, что делать дальше, и объясняет почему; повторение через 1, 3 и 7 дней |
| 🌗 **Две темы** | «тёмная тетрадь в клетку» и светлая (для проектора) |

## Как устроено

Python + Flask (сервер), SQLite (база прогресса), HTML/CSS/JavaScript (страницы и тренажёры).
Подробное объяснение простым языком — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```
app.py              — сервер и страницы сайта
tutor/              — «мозг»: база, генераторы задач, проверка ответов, умный репетитор
content/            — тексты уроков и вопросы тестов (JSON)
templates/          — шаблоны страниц, тренажёры и иллюстрации
static/             — оформление и скрипты
tests/              — автотесты (pytest)
docs/               — документация, журнал разработки, все вопросы курса
```

## Проверка

```
.venv\Scripts\python.exe -m pytest
```

77 автотестов проверяют генераторы задач (тысячи случайных задач), распознавание ошибок,
правила умного репетитора, все 12 уроков и работу страниц.

## Как создавался

Проект сделан методом **вайб-кодинга**: автор продумал продукт, принял все решения
(темы, тренажёры, дизайн, правила репетитора) и тестировал результат, а программный код писал
ИИ-ассистент Claude по его заданию. Весь ход работы записан в [docs/DEVLOG.md](docs/DEVLOG.md).
